# Старт в новой сессии Claude (claude.ai/code)

## Что сделать пользователю
1. claude.ai/code → новая задача → в выборе репозитория указать **sklddjewiodjewi/swim-tool**.
2. В первом сообщении приложить `swim-tool.zip` и написать:
   «Распакуй swim-tool.zip в корень репозитория, закоммить и запушь в main. Дальше работаем по CONTEXT.md».

## Что сделать Claude в новой сессии
1. Распаковать архив так, чтобы в корне репозитория оказались: `START.md`, `CONTEXT.md`, `README.md`,
   `swim_tool.html`, `nhatrang-water/`, `data/` (папку-обёртку `swim-tool/` из архива не переносить).
2. Проверить, что в файлах нет секретов (ключ Apps Script KEY, ссылка `#sync=…`, токены). В `apps-script.gs` KEY — заглушка.
3. Коммит «Морской навигатор заплыва + прозрачность v3.7, контекст и последние данные», push в `main`.
4. Прочитать `CONTEXT.md`, затем оба README. Ответить пользователю коротко: что залито, ссылка на репозиторий.
5. Дальше — по правилам из `CONTEXT.md`: замечания копить, код не генерировать до «генери»;
   после «генери» — сделать, проверить, обновить README, **закоммитить и запушить**, прислать файл `swim_tool.html`.

## Важно
- Репозиторий должен быть **Private**: в `data/` вес и координаты заплывов.
- Данные пользователя живут в его браузере (localStorage); `data/` — резервная копия на 03.11.2026.
  Восстановление у пользователя: кнопка ⬆️ на панели «История» → `data/swim_history_2026-11-03.json`.
- GitHub Pages (публикация как сайт) — только по просьбе пользователя; для бесплатного аккаунта нужен публичный
  репозиторий, тогда `data/` из него убрать.
