    По дням

    Факт — видимость в метрах (3,5) или отклонение от основного прогноза (+1, −2), отдельно за утро и вечер. Пусто — удалить. Под прогнозом стратегии — её ошибка: плюс значит завысила. * — прогноз задним числом по фактической погоде. Прилив: ↑ прилив, ↓ отлив, число — уровень моря в конце окна относительно среднего. Волна — максимум с полудня накануне до конца окна, ветер и температура — средние по окну, УФ — максимум. ↘ — ветер с моря.

    Как это устроено

    При каждом открытии страница берёт данные Open-Meteo и сохраняет снимок входных данных на каждую дату: дождь по часам в городе и в бассейне реки Кай, волну (высота, период, направление), ветер, облачность, уровень моря, температуру воды, течение и расход реки. Для прошлых дней — по фактической погоде, для будущих — отдельный снимок на каждый день выпуска прогноза.

    Стратегия — это алгоритм плюс набор данных, которые он берёт из снимка. Все активные стратегии считаются по всем снимкам, результаты сохраняются. Новая стратегия сразу пересчитывается по всей накопленной истории. Изменённая стратегия — это новая стратегия с новым кодом, старая уходит в архив вместе со своей историей.

    Данные: Open-Meteo — Forecast, Marine и Flood API (GloFAS), бесплатно для некоммерческого использования.
